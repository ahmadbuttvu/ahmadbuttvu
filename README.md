## 🚀 Featured Security Projects

- 🛡️ **[MapSploit Framework](https://github.com/ahmadbuttvu/MapSploit)**  
  An automated, non-intrusive vulnerability mapping framework that bridges `Nmap` service reconnaissance (`-sV`) with `Metasploit RPC` (`msfrpcd`) to safely identify and rank exploit modules without executing active payloads, complete with false-positive filtering and HTML reporting.
- 📡 **[IntruSniff](https://github.com/ahmadbuttvu/intrusniff)** *(CS619 Final Year Project)*  
  A Python and `Scapy`-based signature and rule-based Network Intrusion Detection System (NIDS) designed to monitor network interfaces, analyze packet payloads, and detect volumetric floods (SYN/UDP/ICMP), port scans, SQLi, and XSS in real-time.
